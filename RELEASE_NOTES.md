# ControllerHub 1.0.0

Connect a Switch 2 Pro Controller or DualSense to Windows 11 x64. The new WebView2 interface shows the progress of device discovery, connection and input initialization. A green check confirms when game output is ready. First launch uses English. Choose Simplified or Traditional Chinese in **Settings & logs → Language**. Existing language preferences are respected.

### Downloads

- **ControllerHub-v1.0.0-portable-win-x64.exe** includes the .NET runtime. Run the EXE directly.
- **ControllerHub-v1.0.0-win-x64.zip** requires the .NET 10 Desktop Runtime x64. Extract the whole ZIP, then run ControllerHub.exe.
- Each download has a matching SHA-256 checksum. Virtual gamepad output requires the usbip-win2 Client driver, installed separately.

Xbox, PS5, Pro1 and Steam / Pro2 output modes are available. Advanced feedback depends on the game and connection method. DualSense Bluetooth, long-running audio and performance, and HidHide still need further hardware validation.

## ControllerHub 1.0.0 發布說明

在 Windows 11 x64 上連接 Switch 2 Pro 或 DualSense 手柄。新版 WebView2 介面依序顯示搜尋裝置、建立連線及初始化輸入的進度。綠色勾號表示遊戲輸出已就緒。首次啟動預設使用英文，可在 **Settings & logs → Language** 切換為繁體中文或簡體中文。更新後會沿用已儲存的語言。

### 下載

- **ControllerHub-v1.0.0-portable-win-x64.exe** 已包含 .NET 執行階段，可直接執行。
- **ControllerHub-v1.0.0-win-x64.zip** 需要 .NET 10 Desktop Runtime x64。請完整解壓縮後執行 ControllerHub.exe。
- 各下載檔案均附 SHA-256 校驗碼。使用虛擬手柄輸出時，請另行安裝 usbip-win2 Client 驅動程式。

提供 Xbox、PS5、Pro1 及 Steam / Pro2 四種輸出模式。進階回饋功能取決於遊戲與連線方式。DualSense 藍牙、長時間音訊與效能，以及 HidHide 仍待進一步實機驗證。
