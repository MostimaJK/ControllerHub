# 後續驗收清單

本文件列待完成的驗收，不把程式已實作等同於已驗收。既有證據見[驗收狀態](validation.md)。

- [ ] 記錄 Windows 組建、藍牙驅動、手柄韌體及發布包雜湊。
- [ ] 使用可正常無線喚醒的 DualSense 驗證藍牙輸入、退出與回饋。
- [ ] 四條來源／傳輸路徑驗證按鍵、搖桿、輸出、回饋與斷開後釋放。
- [ ] 首次配對、已配對重連、USB／藍牙切換和睡眠喚醒各反覆測試並記錄成功率。
- [ ] 持續遊玩至少 60 分鐘，記錄斷線、回報間隙、CPU 與記憶體；不將接收頻率當作端到端延遲。
- [ ] 在目標遊戲分開驗證 Xbox 輸入、PS5 識別、觸覺、扳機與六軸軸向。
- [ ] 按住映射鍵時切配置／斷線，不黏鍵；震動／扳機在退出與故障後確實解除。
- [ ] 有限音訊測試通過後再逐步驗證較長工作階段；留意既有鍵鼠受影響問題是否再現。
- [ ] 可選 HidHide 的白名單、隱藏、恢復與卸載流程實機驗收。
- [ ] 介面在 DPI 100%／150%／200% 回歸，錯誤與取消流程可用。
- [ ] 在乾淨 Windows 環境驗證安裝、升級、設定保留及完整發布包。
- [ ] 隨發布版本保存對應原始碼、依賴修訂、補丁與授權，公開截圖及報告不含個人資料。
