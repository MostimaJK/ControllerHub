## 四種虛擬輸出

Xbox、PS5、Pro1、Steam / Pro2 均已有 Windows 消費端檢查。PS5／Pro1 六軸讀回與 Pro2 初始化後的連續串流已驗證。這些是 Windows 裝置與資料通道驗證，尚未代表 Steam／SDL／所有遊戲相容性均通過。

## 現階段範圍

本版以**單手柄工作階段**為主。包含連接與狀態顯示、GL／GR／C 本機映射、震動、進階觸覺、體感、遊戲配置，以及本機設定保存／備份／恢復。

以下不在已完成範圍：多手柄並行、完整一般鍵位編輯器、鍵鼠巨集、耳機／麥克風音訊路由。尚待工作還包括 HidHide 實機驗收、重連／睡眠喚醒壓力測試、長時間性能與遊戲回歸。完整表見[驗收狀態](development/validation.md)。
