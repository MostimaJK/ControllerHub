# 已知問題與待驗收項目

目前原始碼為 v0.3.4 Preview 候選版；GitHub 已發布版本須以 Releases 為準。完整狀態見 [集中驗收記錄](development/completion.md)。

## 已知問題

- **USB 持續停滯仍可能需要重新插線**：0.3.1 已修正可重試的停止寫入過早判失敗；但若 USB 寫入持續無法完成，請關閉程式、拔線等 5 秒、重新插線並短按 Home。反覆初始化曾另見 `CommandTimedOut`；尚未宣稱這兩種底層狀態完全修好，見 [修正驗證](development/release-fix.md)。

1. **Switch 2 USB 首次原生讀取可能失敗**：重新插線後曾出現 `ReadCompletionRejected`；自動重試約一秒後可恢復。最新實測完整連接／Xbox 輸出／退出成功，但根因仍待修復。
2. **音訊轉震動仍為實驗功能**：早期曾導致程式卡頓並影響無線鍵盤。已修正 UI 執行緒佔用、工作優先級、佇列錯誤與停止邏輯；後續受限測試確認有震動且鍵鼠正常，但尚未完成長時間穩定性驗收。預設關閉。
3. **虛擬 PS5 不保證遊戲一定識別**：同一遊戲能識別實體 DualSense，也可能拒絕虛擬裝置。先以 Xbox 模式確認基本遊戲輸入。

## 仍待驗收

- DualSense 藍牙與藍牙進階回饋；現有實測手柄無法正常無線喚醒，未證明具體故障原因。
- Steam／SDL／個別遊戲的六軸軸向、觸覺與自適應扳機相容性。
- 長時間音訊、CPU／記憶體佔用、體感漂移。
- 反覆配對、USB／藍牙切換、睡眠喚醒、自動重連與配置切換。
- HidHide 防重複輸入的完整實機驗收。
- 不同 DPI、乾淨 Windows 環境與正式發布包回歸。

## 已修正並保留回歸檢查

- 0.3.2 修正重複輸入 FIFO 積壓及斷流時維持舊扳機狀態的風險；《異環》長時間駕駛體感仍待驗收，見 [延遲修正記錄](development/latency-fix.md)。

- 輸入與音訊工作捕捉 UI 執行緒，造成介面阻塞。
- 只有一個快取封包或虛擬端點尚未出現，卻顯示連接成功。
- 四聲道音訊格式未保留端點 channel mask／subformat。
- HD 靜音封包錯誤地終止通道，後續震動無法恢復。
- USB 退出與 publication 收尾／一般回呼忙碌發生競態，導致清理誤判失敗。

請勿把這份清單或介面上的測試按鈕視為所有遊戲都已通過的保證。
