# 故障排查

| 現象 | 建議處理 |
|---|---|
| EXE 提示缺少執行階段 | 安裝 .NET 8 **Desktop Runtime x64**，並確認 ZIP 已完整解壓 |
| USB 沒有輸入 | 換可傳資料的 USB 線，確認選對手柄／傳輸方式，退出其他映射程式；Switch 必要時短按 Home |
| 藍牙搜尋不到 Switch | 首次配對長按 SYNC；已配對先短按 Home。確認 Windows 藍牙開啟、主板天線已連接 |
| 有實體輸入但沒有遊戲輸出 | 檢查 usbip-win2 Client 驅動及是否要求重啟；先選 Xbox 模式 |
| 遊戲收到兩份輸入 | 檢查其他映射工具、Steam Input 是否同時接管；HidHide 為可選方案，目前未完成實機驗收 |
| PS5 模式不識別，Xbox 可以 | 遊戲可能只支援某些 DualSense 識別／傳輸方式；先用 Xbox，回報遊戲名稱和版本 |
| 直接測震動成功，但遊戲不震 | 再測 Xbox 回饋鏈路；確認遊戲震動選項及虛擬輸出模式 |
| 音訊轉震動沒反應 | 選實際有聲音的輸出端點，檢查增益、來源是否靜音；此功能仍在有限測試階段 |
| 扳機沒有阻力 | 僅 DualSense 有阻力硬體；確認遊戲真的提供自適應扳機回饋，USB 路徑已測、藍牙未驗收 |
| 退出顯示釋放未完成 | 正常關閉程式並保留診斷；不要同時啟動另一個映射程式。必要時重新插線後再試 |

## 如何回報

提供 Windows 組建、手柄型號／韌體、USB 或藍牙、輸出模式、遊戲名稱／版本與其他映射程式狀態，並描述操作步驟、預期和實際結果。

在「診斷與設定」先預覽報告，確認沒有要保密的資料後再附上。原始 `session.log` 可能包含本機環境資訊，不必直接公開整個設定資料夾。設定仍位於 `%LOCALAPPDATA%/ControllerFusion`。

若音訊測試時再次影響鍵鼠，先退出 ControllerHub，恢復後保持音訊功能關閉並回報，不要連續反覆啟用。
